# Portfolio — Guillermo Yarull

Sitio personal estático hecho con [Analog](https://analogjs.org) (Angular), desplegado en Cloudflare Workers como sitio estático.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # salida estática en dist/analog/public
```

Las convenciones del proyecto están en [CLAUDE.md](CLAUDE.md) y los criterios de calidad en [docs/CRITERIA.md](docs/CRITERIA.md).
